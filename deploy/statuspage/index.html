Reproduce it yourself

No trust required — fork the repo and run the same workflow on your own runner:

1. Fork github.com/Dario-Zela/quorum
2. Actions tab → enable workflows
3. "Chaos demo" → Run workflow

Or locally with Docker:

cd deploy
docker compose up -d --build
docker compose run --rm bench          # load generator
INTERVAL=30 ./chaos.sh                 # leader-killing loop
docker compose exec node1 quorum-cli -cluster \
  "1=node1:7201,2=node2:7201,3=node3:7201,4=node4:7201,5=node5:7201" watch
